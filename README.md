# 齿轮同步带传动设计计算器 · DriveDesigner

一款 Windows 桌面计算工具，覆盖 **同步带传动几何**、**渐开线齿轮几何**、
**多级传动链速比** 与 **整机速度换算** 四类计算。
界面与同门的 *O 形密封圈设计计算器（OringDesigner）* 共用一套视觉与交互规范，
合称「**设计计算器家族**」。

本程序的计算口径取自参考表格 `L20齿轮同步带计算.xlsx`，全部数值已逐位对齐
（见 `tools/selftest.py`，172 项断言全部通过）。

## 二、功能与页签

| 页签 | 对应参考表格 | 主要内容 |
|---|---|---|
| **同步带传动** | S8M 同步带计算 | 23 种齿形、带轮几何、带长与中心距（正/反算）、包角与啮合齿数 |
| **齿轮传动** | 齿轮齿形与中心距 | 渐开线几何、变位、斜齿、不根切校核 |
| **传动链与速度** | 多级齿轮链 + 履带 + 滚刷速度 | 逐级传动比、累计传动比、整机速度换算 |
| **规格库** | — | 齿形参数表、带轮最小齿数、GB/T 1357 模数系列 |
| **使用说明** | — | 全部公式、口径说明与免责声明（F1 直达） |

三个计算页均支持：输入即时重算（240 ms 防抖）+ 「开始计算」按钮、
「重置」回到参考表格的典型工况、「导出报告」生成 HTML / TXT 设计报告。

## 三、计算口径

### 同步带（节距 P，节顶距 δ，齿数 Z，带齿数 Zb）

| 项目 | 公式 |
|---|---|
| 节圆直径 | `PD = Z · P / π` |
| 齿顶圆直径 | `OD = PD − 2δ` |
| 带长 | `L = Zb · P` |
| 带圆形直径 | `L / π` |
| 中心距（简化，与表格一致） | `CD = (L − (Z₁+Z₂)·P/2) / 2` |
| 中心距（精确解） | 严格求解 `L = 2C·cosφ + π(D₁+D₂)/2 + φ(D₂−D₁)`，`φ = asin((D₂−D₁)/2C)` |
| 小轮包角 | `θ = 180° − 2·asin((PD₂ − PD₁) / (2·CD))` |
| 啮合齿数 | `Zm = Z · θ / 360` |

支持**反算**：填「已知中心距」→ 反求所需带齿数 → 取整到整数齿 → 给出实际带长与实际中心距。

### 渐开线齿轮（法向模数 mn，齿数 z，螺旋角 β，变位系数 x）

| 项目 | 公式 |
|---|---|
| 分度圆直径 | `d = mn · z / cos β` |
| 齿顶圆直径 | `da = d + 2mn(ha* + x)` |
| 齿根圆直径 | `df = d − 2mn(ha* + c* − x)` |
| 基圆直径 | `db = d · cos αt` |
| 标准中心距 | `a = mn(z₁+z₂) / (2 cos β)` |
| 无侧隙啮合 | `inv αw = inv α + 2(x₁+x₂)·tanα / (z₁+z₂)` |
| 中心距变动 | `y = (z₁+z₂)/2 · (cosα/cosαw − 1)`，`a = a_std + y·mn` |
| 不根切最小变位 | `x_min = ha* − z·sin²α / 2` |

默认 `ha* = 1`、`c* = 0.25`、`α = 20°`（正常齿标准齿条），`z_min ≈ 17.1`。

### 传动链与整机速度

- 单级传动比 `i = Z₁ / Z₂`（Z₁ 为主动轮），累计 `i_总 = Π(Z₁/Z₂)`
- **i 定义为「输出转速 / 输入转速」**：`i < 1` 减速，`i > 1` 增速；减速比 `u = 1/i`
  —— 与参考表格一致（表里 `D6 = B6/C6`）
- 驱动轮：`ω = v/R`（rad/s）、`n = 60v/(2πR)`（r/min）
- 反推电机：`ω_电机 = ω_驱动轮 / i_驱动轮前`
- 执行机构：`ω_执行 = ω_驱动轮 × (i_执行 / i_驱动轮)`，`v_执行 = ω_执行 · R_执行`
- 「驱动轮前累计 i」自动取**第一个同步带级之前**的齿轮级累计（= 表中 `F12`）；
  「执行机构累计 i」自动取**整条链**累计（= 表中 `F28`）；
  二者之比即表中「行走滚刷比」

## 四、标准依据

- `GB/T 11361` 同步带传动 梯形齿带轮
- `GB/T 11616` 同步带 尺寸系列
- `ISO 5294 / ISO 5296` 同步带与带轮国际系列
- `GB/T 1357` 渐开线圆柱齿轮 模数
- `GB/T 10095` 渐开线圆柱齿轮 精度制
- 机械设计手册 / 米思米 · 盖茨 · 优霓塔样本（带轮最小齿数、节顶距取值）

## 五、免责声明

本程序按上述标准的**通用工程取值**自动计算，用于**方案比选与初步设计**。
正式投产前请以最新版标准原文、供应商样本实测数据以及样机验证结果复核，
尤其是涉及高速、重载、有安全强制要求的场合。

另需注意两处口径：

1. **节顶距 δ**：GB/T 11361 与 ISO 5294 未强制规定，各品牌齿槽略有差异，
   本程序取行业通行值（与盖茨 / 优霓塔 / 米思米口径一致）用于计算与示意。
   **精加工前请以所选品牌样本的齿槽图复核。**
2. **中心距简化式**：为与参考表格保持一致而保留；两轮齿数差较大时以程序同时
   给出的**精确解**为准，出图建议采用精确解。

**同步带本身的强度校核**（许用功率、带宽、齿根剪切）不在本程序范围内，
需按 `GB/T 11362` 或供应商选型手册另行计算。

## 六、开发与运行

### 环境

需要 Python 3.9+ 与 PySide6-Essentials：

```bat
pip install -r requirements.txt
python app.py
```

### 自检

```bat
python tools\selftest.py            :: 全量（数值 + 示意图几何 + 界面冒烟 + 截图）
python tools\selftest.py --no-ui    :: 只跑数值校验，不出界面
```

自检产物落在 `tools/out/`：`selftest.txt` 为报告，`shot_*.png` 为五个页签的截图。

> 截图**不要**设 `QT_QPA_PLATFORM=offscreen`：该平台没有字体数据库，
> 中文会渲染成豆腐块，容易误判排版。正确做法是默认平台 +
> `WA_DontShowOnScreen` 属性，拿到真实字体渲染的画面。

### 打包为单文件 exe

```bat
build.bat
```

脚本会先用 `tools/make_icon.py` 生成 `app.ico`（与运行时窗口图标同一套画法，
任务栏 / 标题栏 / exe 文件图标天然统一），再调 PyInstaller 打成单文件。
产物在 `dist\齿轮同步带传动设计计算器.exe`。

> **不要 exclude `PySide6.QtSvg`** —— 页眉的 GitHub / 地球图标由它渲染，
> 排除后图标会退化成占位方块。

## 七、家族一致性

与 `OringDesigner`（O 形密封圈设计计算器）共用以下规范：

- 同一套主题常量与 QSS（`ui/theme.py`），浅色工程风：底 `#F4F6F9`、主色 `#2F6FED`
- 同一套图标接口（`ui/icons.py`），轴测与画法风格一致
- 同一套卡片 / 指标卡 / 校验框 / 报告输出控件（`ui/pages.py`）
- 同一套打包与自检流程（`build.bat`、`tools/make_icon.py`、`tools/selftest.py`）
- 页眉统一标注「设计计算器家族」

新增家族成员时，建议直接复制 `ui/theme.py`、`ui/icons.py` 的通用部分与
`tools/` 三个脚本，只替换 `app_icon_image()` 与 `core/` 计算内核。
